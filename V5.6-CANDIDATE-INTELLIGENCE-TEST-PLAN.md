# IntelliHire V5.6 — Candidate Intelligence Test Plan & Verification Matrix

## 1. Overview

This test plan validates the end-to-end functionality, security, resilience, and user experience of the Unified Candidate Intelligence Dashboard introduced in IntelliHire V5.6.

---

## 2. Test Execution Matrix

### 2.1 Backend Aggregation & Intelligence API

| Test ID | Test Scenario | Input Data | Expected Output | Status |
|---|---|---|---|---|
| `API-01` | Candidate Intelligence Retrieval (General) | `GET /api/candidates/:id/intelligence` | Returns 200 with candidate, resume, academic, coding, projects, certificates, applications, scores, recommendation, strengths, gaps. | ✅ PASS |
| `API-02` | Job-Specific Intelligence Retrieval | `GET /api/candidates/:id/intelligence?jobId=:jid` | Returns 200 with job-matched skills, missing skills, semantic match score, relevant projects, relevant certificates, and target job context. | ✅ PASS |
| `API-03` | Candidate Self Intelligence View | `GET /api/candidates/me/intelligence` with Candidate JWT | Returns 200 with authenticated candidate's own intelligence profile. | ✅ PASS |
| `API-04` | Recruiter Hiring Action | `POST /api/candidates/:id/action` with status `Shortlisted` | Returns 200; updates or creates Application document with status `Shortlisted` and adds timeline audit entry. | ✅ PASS |
| `API-05` | Recruiter Move to Interview | `POST /api/candidates/:id/action` with status `Interview` | Updates status to `Interview` and records timeline note. | ✅ PASS |
| `API-06` | Non-Existent Candidate ID | `GET /api/candidates/000000000000000000000000/intelligence` | Returns 404 with error message "Candidate not found". | ✅ PASS |
| `API-07` | Unauthorized Candidate Access | Candidate A requests Candidate B's intelligence | Returns 403 Forbidden with "Access denied". | ✅ PASS |
| `API-08` | Missing Optional Modules | Candidate with no projects, certificates, or coding profile | Returns 200 with empty arrays/defaults; zero null pointer exceptions. | ✅ PASS |

| Test ID | Test Scenario | Verification Condition | Expected Result | Status |
