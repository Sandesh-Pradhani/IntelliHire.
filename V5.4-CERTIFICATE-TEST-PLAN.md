# IntelliHire V5.4 Certificate Test Plan

## Backend API
- Candidate creates a certificate with required title, issuer, and issue date.
- Candidate reads all certificates through `GET /api/certificates`.
- Candidate reads one owned certificate through `GET /api/certificates/:id`.
- Candidate updates an owned certificate through `PUT /api/certificates/:id`.
- Candidate deletes an owned certificate through `DELETE /api/certificates/:id`.
- Duplicate certificate creation returns `409`.
- Missing title, issuer, or issue date returns `400`.
- Expiry date before issue date returns `400`.
- Malformed credential or evidence URL returns `400`.
- Candidate A cannot read, update, delete, verify, or score Candidate B certificate.
- Unauthenticated calls return `401`.
- Wrong-role candidate/recruiter calls return `403`.

## Evidence Upload
- PDF upload succeeds and stores only a URL/reference plus file metadata.
- PNG upload succeeds.
- JPG/JPEG upload succeeds.
- Unsupported file type is rejected.
- Oversized file is rejected.
- Uploaded filename is replaced with a generated safe filename.
- Evidence URL does not expose sensitive local filesystem paths.

## Verification
- New certificate starts as `unverified` unless credential or evidence data moves it to `pending`.
- `/verify` marks expired certificates as `expired`.
- `/verify` keeps certificates without credential/evidence as `unverified`.
- `/verify` can mark certificate as `pending` or `verified` only within the supported workflow.

## AI Scoring
- FastAPI `/certificate-score` returns `certificateScore`, `relevanceScore`, contribution fields, and recommendation.
- Job-required skills increase relevance when they overlap certificate skills.
- Expired certificates receive reduced freshness and verification contribution.
- Express `/api/certificates/:id/score` persists returned score on the certificate.
- `/unified-score` accepts optional `certificateScore` and returns certificate breakdown.

## Frontend
- Candidate certificate page loads stats, empty state, loading state, and cards.
- Add form validates required fields and shows server errors without `alert()`.
- Edit form pre-fills values and saves updates.
- Delete removes the certificate from the list.
- Evidence file can be selected and uploaded.
- Credential/evidence links render only when present.
- Certificate score button shows loading and updates card score.
- Mobile layout stacks without text overlap.
- Desktop layout shows stats and certificate cards cleanly.

## Regression
- Authentication still works.
- Resume upload and history still work.
- ATS scoring still works.
- Skill extraction and semantic matching still work.
- Academic profile still works.
- Coding profile still works.
- Project portfolio and project scoring still work.
- Applications, candidate ranking, recruiter dashboard, notifications, and feedback still load.
- FastAPI `/docs` and `/redoc` include the new certificate scoring endpoint.
