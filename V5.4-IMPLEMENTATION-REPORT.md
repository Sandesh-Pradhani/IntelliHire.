# IntelliHire V5.4 Certificate Management Implementation Report

## Objective
Implemented certificate management as an incremental upgrade to the existing IntelliHire candidate profile, backend API, and FastAPI scoring engine.

## Existing Architecture Reused
- Reused Express, MongoDB/Mongoose, JWT auth, role middleware, multer upload middleware, React/Vite, existing candidate layout, shared stat cards, and FastAPI router/service/schema patterns.
- Reused the existing `Certificate` model instead of creating a duplicate model.

## Files Added
- Backend: `server/controllers/certificateController.js`, `server/services/certificateService.js`, `server/routes/certificateRoutes.js`.
- Frontend: `client/src/services/certificateService.js`, `client/src/pages/Certificates.jsx`, certificate card/form/score/badge components.
- AI engine: `ai-engine/app/routers/certificate_scoring.py`, `ai-engine/services/certificate_scoring.py`, `ai-engine/schemas/certificate_schema.py`.

## Files Modified
- `server/models/Certificate.js`, `server/middleware/uploadMiddleware.js`, `server/server.js`.
- `client/src/services/http.service.js`, `client/src/services/portfolio.service.js`, `client/src/routes/CandidateRoutes.jsx`, `client/src/navigation/candidateMenu.js`, `client/src/pages/CandidateDashboard.jsx`, `client/src/pages/Portfolio.jsx`.
- `ai-engine/app/main.py`, `ai-engine/app/routers/coding_profile.py`, `ai-engine/services/coding_scoring.py`.

## Database Changes
- Expanded certificate metadata: issuer, dates, expiry, credential URL/ID, skills, category, description, verification status, evidence reference, evidence metadata, and embedded certificate score.
- Added indexes for candidate ownership, issuer, category, verification status, score filtering, and duplicate lookup.

## API Endpoints
- `POST /api/certificates`
- `GET /api/certificates`
- `GET /api/certificates/stats`
- `GET /api/certificates/:id`
- `PUT /api/certificates/:id`
- `DELETE /api/certificates/:id`
- `POST /api/certificates/:id/verify`
- `POST /api/certificates/:id/score`
- `GET /api/certificates/candidate/:candidateId`

## FastAPI Endpoints
- `POST /certificate-score`
- Existing `POST /unified-score` now accepts optional `certificateScore`.

## Certificate Scoring Formula
- Skill relevance: 50%.
- Verification/evidence contribution: 20%.
- Credential freshness: 15%.
- Issuer/category information: 15%.
- This is certificate relevance and evidence scoring, not certificate authenticity detection.

## Unified Candidate Score
- Semantic: 28%.
- ATS: 18%.
- Academic: 14%.
- Coding: 18%.
- Projects: 14%.
- Certificates: 8%.

## Verification Workflow
- Default: `unverified`.
- Credential or evidence submitted: `pending`.
- Explicit supported workflow update: `verified`.
- Expired certificates: `expired`.
- No external issuer verification is claimed.

## Frontend Workflow
- Candidate can view certificate statistics, add/edit/delete certificates, upload evidence, view verification state, and request scoring.
- Candidate dashboard now includes certificate count.
- Existing portfolio certificate service calls now route to the V5.4 certificate API.
- Recruiter portfolio detail modal now shows the selected candidate's certificates with verification status, skills, and certificate score.

## Security Considerations
- JWT auth and role checks protect certificate APIs.
- Ownership checks prevent candidate-to-candidate modification.
- Recruiter access is read-only through the recruiter endpoint.
- Uploads are type-limited to PDF/PNG/JPG/JPEG and size-limited to 5 MB.
- Uploaded filenames are replaced with generated names.
- URL validation rejects malformed credential/evidence URLs.

## Known Limitations
- Evidence storage uses local disk and should be moved to durable storage for production.
- Verification is workflow-based; genuine issuer verification is future work.
- Recruiter dashboard analytics are not deeply expanded beyond certificate retrieval.

## Future Improvements
- Add issuer API integrations for real verification.
- Add object storage for evidence files.
- Add automated backend and frontend test coverage.
- Add recruiter-wide certificate analytics widgets.
