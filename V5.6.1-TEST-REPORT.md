## Known Limitations

1. **HackerRank API**: May be rate-limited or blocked by HackerRank's infrastructure. Graceful degradation implemented.
2. **No unit tests**: Client and server lack test frameworks (Jest, Vitest, Supertest). Only AI engine has 28 pytest tests.
3. **No E2E tests**: No Cypress or Playwright configured.
4. **Bundle size**: 642KB JS bundle exceeds 500KB recommendation. Code splitting recommended for V6.
5. **SBERT model**: Sentence-transformers model (~80MB) downloads on first use. May be slow in production cold starts.
